# skills/

Skills land here as fixes ship. When a retro approves a fix whose solution is
a skill — a writing style, a workflow, a rule that needs its own home — the
resolve lane's worker team creates it here, and from the next session on it
shapes how the AI works with you.

`example-style/` is a deletable example showing the shape; remove it whenever
you like. `file-issues/` is a skeleton, not an example: adapt it to your
tracker if `retroloop.md` says you track issues elsewhere, and delete it if you
don't.
